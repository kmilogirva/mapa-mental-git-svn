# Mapa mental: Herramientas de control de versiones (Git y SVN)

Taller **AA2**: mapa mental interactivo sobre control de versiones, con énfasis en Git y SVN.

## Contenido

El mapa parte del tema central y se ramifica en seis ramas:

1. **Conceptos fundamentales**: qué es el control de versiones, conceptos clave, tipos y ventajas.
2. **Git**: control distribuido, estructura de trabajo (directorio, staging area, repositorio local y remoto), comandos esenciales, ramas, fusiones y resolución de conflictos.
3. **SVN (Subversion)**: control centralizado, comandos principales, estructura `/trunk`, `/branches` y `/tags`, ventajas y limitaciones frente a Git.
4. **Comparativa Git vs SVN**: modelo, flexibilidad, escalabilidad, uso sin conexión y escenarios recomendados.
5. **Buenas prácticas**: commits descriptivos, evitar conflictos, ramas temáticas y coordinación en equipo.
6. **Errores comunes a evitar**: no documentar cambios, trabajar en la rama principal e ignorar conflictos.

## Cómo usarlo

Abre [`mapa-mental.html`](mapa-mental.html) en cualquier navegador. No necesita instalación ni conexión a internet.

| Acción | Cómo |
|---|---|
| Editar un tema | Doble clic (Enter guarda, Esc cancela) |
| Agregar subtema / tema hermano | `Tab` / `Enter` |
| Borrar / deshacer | `Supr` / `Ctrl+Z` |
| Plegar o desplegar una rama | Clic en el círculo o `Espacio` |
| Moverse y hacer zoom | Arrastrar el fondo y usar la rueda del mouse |
| Exportar a PDF | **Expandir todo** → **Exportar PDF** → *Guardar como PDF* |
